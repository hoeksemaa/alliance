# Alliance

A turn-based web game for about 15 players, based on Tank Turn Tactics.

## Rules so far

- The board is 20 × 20.
- At 22:00 each day, each living player gets 1 action point (AP).
- Move one square: 1 AP.
- Attack a player in range: 1 AP.
- Give 1 AP to a player in range: 1 AP.
- Extend your range by 1: 2 AP.
- Each player selects a country flag at the start of the game.
- Dead players form a jury and vote.

The game runs on Vercel. All players see a move in less than one minute.
